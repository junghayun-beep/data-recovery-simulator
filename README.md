# 디지털 데이터 복원 정확도 비교 시뮬레이터 (Chromebook 지원)

## 크롬북에서 실행하기

1. ZIP 파일을 크롬북의 **파일** 앱에서 다운로드 폴더에 저장합니다.
2. ZIP 파일을 두 번 클릭하고 압축을 풉니다.
3. 압축 해제된 폴더에서 `index.html`을 찾습니다.
4. `index.html`을 두 번 클릭하거나 마우스 오른쪽 버튼으로 **Chrome에서 열기**를 선택합니다.
5. 실험 조건을 설정하고 **실험 실행**을 누릅니다.

별도 앱, Python, 개발 도구 설치는 필요하지 않습니다. 화면이 작은 크롬북에서도 사용할 수 있도록 반응형 화면과 터치 조작 영역을 적용했습니다.

### 인터넷 연결
- 실험 계산과 CSV 파일 생성은 브라우저 안에서 실행됩니다.
- 그래프 라이브러리(Chart.js)는 인터넷에서 불러오므로 그래프를 표시할 때는 인터넷 연결이 필요합니다.
- 인터넷이 없어 Chart.js를 불러오지 못해도 계산·결과표·CSV 기능은 사용할 수 있습니다.

### 결과 CSV 저장 위치
CSV 다운로드 파일은 ChromeOS의 기본 **다운로드** 폴더에 저장됩니다. 브라우저가 다운로드 확인을 요청하면 허용하세요.

## 파일 구성
- `index.html`: 시뮬레이터 화면
- `style.css`: 반응형 및 Chromebook 터치 UI
- `script.js`: 부호화·오류 발생·복원·통계·그래프·CSV 기능
- `README.md`: 실행 및 연구 안내
- `test-core.js`: 핵심 알고리즘 테스트

## 실험 방식과 해석
- **3회 반복 부호**: 각 비트를 3회 전송하고 다수결로 복원합니다.
- **짝수 패리티**: 데이터 8비트마다 짝수 패리티 1비트를 추가합니다. 오류를 검출하지만 자동 정정하지 않습니다.
- **해밍 (7,4)**: 4비트를 7비트 코드워드로 변환하고 syndrome으로 단일 비트 오류를 정정합니다.
- 오류는 모든 전송 비트에서 독립적으로 발생합니다.
- 패리티 검출률의 분모는 실제 손상된 블록 수입니다. 손상 블록이 하나도 없으면 검출률은 계산 불가로 표시합니다.
- 해밍 다중 오류 오정정은 2개 이상 비트가 손상된 코드워드 중 복원된 데이터가 원본과 다른 경우로 집계합니다.

## 측정 지표
정확도와 BER은 원본 비트열과 복원(또는 패리티 수신) 데이터의 비트 단위 비교로 계산합니다. 반복별 정확도 평균, 표준편차, 정규근사 95% 신뢰구간을 제공합니다. 신뢰구간은 반복별 결과의 독립성을 가정한 근사치입니다.

## 재현성 및 연구 한계
같은 설정과 난수 시드를 사용하면 동일한 결과가 재현됩니다. 본 실험은 독립 비트 오류 모형을 사용하므로 실제 무선 통신의 간섭, 감쇠, 반사, 연속적인 버스트 오류를 완전히 재현하지 않습니다. 해밍 (7,4)는 단일 비트 오류 정정 코드이며 다중 비트 오류를 항상 올바르게 처리하지 않습니다.

## 개발자용 테스트
Node.js가 설치된 환경에서 프로젝트 폴더에서 `node test-core.js`를 실행합니다. Chromebook에서 시뮬레이터를 실행하는 데 Node.js는 필요하지 않습니다.
